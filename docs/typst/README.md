# Typst-отчёты по проекту Contur 2

Восемь typst-отчётов по этапам разработки симулятора. Текст соответствует MD-источникам
в [`../reports/`](../reports/) и поддерживается в синхронизации с фактическим кодом.

## Шаблон

Используется [`smk-sto-004`](https://github.com/tokKurumi/smk-sto) — реализация
СМК СТО 004–2020 МГУ им. Н. П. Огарёва (правила оформления отчётов о лабораторных работах):
A4, поля 30/15/20/20 мм, Times New Roman 14 pt, межстрочный интервал 1.5, нумерация
заголовков и подписей рисунков/таблиц соответствует стандарту. Подключается через
`@preview/smk-sto-004:0.1.0`.

Диаграммы — [`fletcher`](https://typst.app/universe/package/fletcher) (`0.5.8`):
fletcher автоматически подтянет cetz при компиляции.

Каждый файл — самостоятельный отчёт, импортирует общий `_meta.typ` для титульника.

## Заполнение титульника

Перед компиляцией один раз отредактируйте [`_meta.typ`](_meta.typ):

```typst
#let institute  = "<Институт>"
#let department = "<Кафедра>"
#let discipline = "Проектирование компонентов операционных систем"

#let author     = (name: "И.О. Фамилия", direction: "<00.00.00 Название направления>")
#let supervisor = (name: "И.О. Фамилия", position: "<должность>")
#let designation = (direction: "<000000>", variant: "<00>")
```

Все восемь отчётов подхватят значения автоматически.

## Сборка

```bash
typst compile 01_architecture_foundation.typ
```

или все сразу (bash):

```bash
for f in 0*.typ; do typst compile "$f"; done
```

При первом запуске Typst скачает `smk-sto-004` (находится в активной разработке, см [репозиторий](https://github.com/tokKurumi/smk-sto)), `fletcher` и их зависимости из реестра
`@preview`. Дальнейшие сборки идут из локального кэша.

## Структура каждого отчёта

```
= Цель работы                       ← верхнеуровневая цель и список задач
= Реализация                        ← основное содержание (с подразделами ==)
= Заключение                        ← структурный раздел (не нумеруется)
= Список использованных источников  ← структурный раздел (не нумеруется)
```

Оглавление (`#outline()`) намеренно не используется — отчёты компактные.

## Конвенция оформления

- Повествовательный текст на русском, идентификаторы (API, классы, файлы, CMake-флаги) —
    латиницей, как в коде.
- Каждый рисунок и таблица имеют якорь `<fig:label>` / `<tab:label>` и кликабельную
    ссылку из текста через `@fig:label` / `@tab:label`.
- Диаграммы заданы в исходнике через `fletcher.diagram` — редактируются прямо в `.typ`,
    без отдельных бинарных файлов.
